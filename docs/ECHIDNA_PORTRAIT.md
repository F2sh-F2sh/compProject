# Echidna dialogue portrait revision

Replaced the generic straight-hat portrait with a new reference-guided bust based on EchidnaIdle.png. The portrait retains the bent drooping purple hat, gold buckle, shadow face, narrow upright white eyes and original cloak palette.

Saved assets: `assets/sprites/story/portrait_echidna_base.png` is the 64×64 neutral source, and `assets/sprites/story/portrait_echidna.png` contains five 64×64 frames in the established neutral/worried/determined/sad/surprised order. No character/body/gameplay changes.

All five expressions were natively rendered in cottage dialogue on an isolated desktop without OS input. Neutral and sad screenshots were inspected in context. The PNG format audit confirmed native frame sizes, hard alpha and distinct expression frames. No commit or push. Existing shutdown cleanup warnings remain.
